# Анализ данных о ментальном здоровье

## О проекте

Учебный проект, выполненный в рамках курса «Анализ данных на Python» в НИУ ВШЭ.

Цель проекта — исследовать данные о ментальном здоровье и определить факторы, которые могут быть связаны с различиями в показателях психического состояния.

## Задачи

В рамках проекта:

- провела очистку и подготовку данных;
- выполнила исследовательский анализ данных;
- исследовала распределения признаков;
- анализировала взаимосвязи между переменными;
- использовала статистические методы;
- визуализировала результаты анализа;
- сформулировала выводы на основе полученных результатов.

## Этапы анализа

1. Загрузка и изучение данных
2. Очистка и обработка пропусков
3. Exploratory Data Analysis
4. Визуализация распределений
5. Анализ взаимосвязей между признаками
6. Статистический анализ
7. Интерпретация результатов

## Стек

**Python · pandas · NumPy · SciPy · scikit-learn · Matplotlib · Seaborn**
